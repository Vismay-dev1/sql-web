# MemoryVault – Browser-Based Database App

MemoryVault is a web application that simulates a relational database system directly in the browser.

## Features
- Create and manage data in table format
- Store structured data (rows and columns)
- No server or installation required
- Data persists locally in the browser

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Storage (LocalStorage / IndexedDB)

## How It Works
The application mimics database operations using browser-based storage, allowing users to store and retrieve structured data without needing a backend database like MySQL.

## Future Improvements
- Query system (SQL-like interface)
- Data export/import
- Cloud sync
